# Contributing to Ten-Four

Ten-Four is a personal fork of [Handy](https://github.com/cjpais/Handy) by CJ Pais, shared as is.

- **Bugs:** open an issue in this repository with your macOS version, your Mac's chip and steps to reproduce.
- **Ideas:** open an issue and describe what you're trying to do.
- **Pull requests:** welcome, but open an issue first so we can agree on the change.

Please don't send Ten-Four bugs or pull requests to the Handy project.
If a bug also happens in stock Handy, report it there by following [Handy's contributing guide](https://github.com/cjpais/Handy/blob/main/CONTRIBUTING.md).

Build instructions are in [BUILD.md](BUILD.md).
