# Brief: Handy Logo Exploration

- Status: approved
- Date: 2026-09-27
- Repo / area: `design/logo-exploration/`

## Outcome and why

- Build four production-ready, symbol-only identity directions for a quiet, local speech-to-text desktop utility.
- The work is for the product owner to compare and select a distinctive long-term mark.

## Quality bar

- [x] Production-critical
- Every direction needs editable source geometry, deterministic exports, small-size validation, and complete platform bundles.

## Definition of done

- [ ] Three keycap directions and one voice-to-letterforms challenger are visually distinct.
- [ ] Every direction includes editable SVG, 1024px masters, launcher PNG sizes, Tauri platform exports, tray states, and a 1920 by 1080 direction board.
- [ ] Idle assets contain no Tally red, while recording assets use Tally red.
- [ ] Every mark remains legible at 16px and 20px on light and dark surfaces.
- [ ] Active application branding remains untouched until the user selects a direction.

## Scope

- In scope: isolated concept generation, deterministic vector reconstruction, complete export packages, mockups, scoring, and validation.
- Out of scope: replacing active app icons, UI marks, tray assets, the display name, or the current generator.

## Constraints and standard

- Match `DESIGN.md`: calm, exact, native, graphite, minimally decorative, and never cute.
- Preserve all existing tracked and untracked branding work.
- Use Tally red only for active recording.
- Avoid the old hand, pink, microphones, generic waveforms, sparkles, AI orbs, and name-dependent typography.

## Design sketch

- Approach A: use generated bitmap concepts as final artwork.
- Approach B: use generated concepts as visual research, then rebuild them as deterministic vector geometry with a shared export system.
- Chosen approach: Approach B, because production identity assets must be editable, reproducible, and reliable at small sizes.

## Selection gate

Present all four completed systems together and stop for explicit user selection.
Do not integrate a winner during this phase.
