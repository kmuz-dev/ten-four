# Handy Product Facts

> Verified: 2026-09-27

- Handy is a cross-platform desktop speech-to-text application built with Tauri, Rust, React, and TypeScript.
- Its core action is push-to-talk dictation that pastes locally transcribed text into the active application.
- The product emphasizes privacy, offline processing, simplicity, and extensibility.
- The current fork identifies itself as `Handy Personal` in `src-tauri/tauri.conf.json`.
- `DESIGN.md` defines the current visual direction as Tally Light: graphite neutrals, system accent controls, and Tally red reserved for live recording.
- The upstream README states that the Handy name and brand assets are reserved, so this round intentionally avoids a wordmark while naming remains unresolved.
